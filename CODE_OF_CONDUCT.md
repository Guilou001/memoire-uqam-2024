# Code de conduite

Ce projet applique le Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
En résumé : respect, critique des idées et non des personnes, aucune forme de harcèlement. Les manquements se
signalent au mainteneur (voir le profil GitHub Guilou001) et sont traités avec discrétion.
